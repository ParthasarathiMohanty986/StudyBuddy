# 📚 Study Buddy

Study Buddy is a Django-based web application that helps students collaborate, discuss academic subjects, and learn together through subject-specific discussion rooms.

## ✨ Features

- User authentication and login
- Subject-specific discussion rooms
- Peer-to-peer academic discussions
- Collaborative learning environment
- Responsive interface built with Tailwind CSS
- SQLite database integration

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Database:** SQLite

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- pip
- Git

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd study-buddy
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Apply database migrations

```bash
python manage.py migrate
```

### 5. Run the development server

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.

## 💡 How It Works

1. Create an account or log in.
2. Browse available subject-specific rooms.
3. Join a room relevant to your studies.
4. Ask questions and discuss topics with other students.
5. Learn collaboratively by sharing knowledge.

## 🎯 Project Objective

Study Buddy aims to make collaborative learning easier by giving students a shared platform for academic discussions and knowledge exchange. The project was designed to support a community of 50+ students.
